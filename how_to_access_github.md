# How to set up GitHub.com for use with UMN Organizations

All of our code is synced with [GitHub.com](https://github.com) via a UMN-owned [GitHub Organization](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/about-organizations). You can learn more about the UMN Office of Information Technology (OIT) GitHub Organizations via their [docs](https://github-docs.devex.oit.umn.edu/). 

You'll need to follow the steps below to obtain access.

## 1. You will need a GitHub.com account

- You can use any GitHub.com account -- you do not need to create a new account if you already have one. 
- You should choose an account (i.e. username) that you are comfortable sharing with your coworkers. 
- If you do not want to reveal your personal GitHub account to coworkers, create a new GitHub.com account for your UMN activities.
- Create this account using any email address (i.e. your personal Gmail/Yahoo/Outlook or UMN email address). You do not need to create the GitHub account using your UMN email address.
- When setting up your account, add your full name to the account (This makes it easier to see who you are).

## 2. Add your UMN email address to your GitHub.com account

- Go to [https://github.com/settings/emails](https://github.com/settings/emails)
- Make sure your UMN email address is one of your "verified" email addresses (you will need to verify by checking your email)
- The UMN email address does not need to be the primary address on the account

## 3. Request access to a UMN GitHub Organization

- We manage two GitHub orgs, owned by UMN OIT:
    - [https://github.com/umn-msi-mdl](https://github.com/umn-msi-mdl) for Fairview MDL clinical projects
    - [https://github.com/umn-msi-lmnp](https://github.com/umn-msi-lmnp) for all other Lab Med and Pathology related projects
- If you want access to repos in either of these orgs above:
    - Email Todd Knutson and request access: [knut0297@umn.edu](mailto:knut0297@umn.edu)
    - Todd will invite you to join the org (you'll receive an email from GitHub)
    - Check your UMN email account and "accept" the invite to the GitHub org
    - You should be able to access to the organization (however, you still may not see any repos yet)
        - We will need to add your username to a GitHub Team (usually PI-based teams) and that team will be given access to the repo of interest
        - After you are member of the org, any of the MSI analysts can give you access to certain repos via GitHub teams
    - Please email Todd if you have any questions!
